# 网页 AI 群聊

一个本地网页 AI 群聊工具，可以同时向多个网页版 AI 发送消息，并读取、复制、对比、汇总它们的回答。

## 功能

- 支持 ChatGPT、Gemini、DeepSeek、Qwen、豆包等网页模型配置
- 支持并发发送或轮询发送
- 支持图片、PDF、Word、Excel、PPT、文本等附件发送
- 支持复制单个模型的读回结果
- 支持两个模型交换答案并互相对比
- 支持指定一个模型汇总多个模型的回答
- 支持每个模型单独设置规则提示词
- 支持本地网络访问和临时互联网访问链接

## 本地运行

```bash
npm install
npm run build
npm start
```

默认访问地址：

```text
http://127.0.0.1:5174/
```

## 注意

首次使用需要分别打开各模型网页并登录账号。浏览器登录缓存、上传文件、日志和依赖目录不会提交到 GitHub。
